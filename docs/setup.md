# Setup Guide

Use this checklist after creating a repository from this template.

## 1. Rename placeholders

- Replace placeholder project names in `README.md`.
- Update repository URLs and badge links.
- Set the correct package/app/module name in source files.

## 2. Configure repository metadata

- Set repository description and topics.
- Choose visibility (public/private).
- Configure default branch protection rules.

## 3. Prepare automation

- Ensure `.github/workflows/` contains the CI workflows you need.
- Configure required secrets and variables in repository settings.
- Verify workflow permissions are correct for your use case.

## 4. Validate baseline files

- Confirm `LICENSE` matches the intended license.
- Update `CHANGELOG.md` with first project-specific entries.
- Review `TODO.md` and keep only relevant tasks.

## 5. First release prep

- Create an initial version tag (`v0.1.0` or `v1.0.0` depending on readiness).
- Ensure release notes reflect key baseline decisions.
